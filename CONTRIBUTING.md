# Contributing

We welcome community contributions! To keep things consistent, please follow these guidelines:

## Workflow

- Fork the repo and create a feature branch from `main`
- Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `chore:`, `docs:`, etc.)
- Open a Pull Request with a clear description

## Code Style

- TypeScript: use `tsconfig.base.json` rules
- Python: follow [PEP8](https://peps.python.org/pep-0008/)
- Run `npm run lint` before pushing

## Testing

- Add tests where possible
- Do not break existing builds or CI checks

## Communication

- Use Issues to report bugs or request features
- Be respectful and constructive in discussions
